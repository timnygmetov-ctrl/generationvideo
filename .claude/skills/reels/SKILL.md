# Qadam Reels: тема → сценарий → промпты кадров

На входе одна тема (`$ARGUMENTS`). На выходе в корне проекта:

- `scenario.md` — сценарий Reels;
- `prompts/scene-01.md` … `scene-NN.md` — по файлу на сцену, 4–6 сцен;
- `prompts/prompts.json` — те же промпты одним файлом для API (собирает скрипт проверки).

Сначала прочитай [style-guide.md](style-guide.md): якорь стиля, герои и негативный промпт
берутся оттуда дословно.

## Шаг 0. Убрать прошлый прогон в архив

Если в корне уже есть `scenario.md`, перенеси старый прогон, ничего не удаляя:

```bash
cd "$CLAUDE_PROJECT_DIR" && [ -f scenario.md ] && d="archive/$(date +%Y-%m-%d-%H%M)" && mkdir -p "$d" && mv scenario.md "$d/" && { [ -d prompts ] && mv prompts "$d/"; true; }
```

## Шаг 1. Разобрать тему

Для кого: люди из Казахстана, Кыргызстана, Узбекистана, Таджикистана и Туркменистана
(именно в таком порядке, если перечисляешь), которые недавно прилетели в UK и подали
на убежище. Часто без английского, без документов, в тревоге.

Определи:
- **один главный вопрос**, на который отвечает ролик (не три);
- **2–4 факта**, которые человек должен унести. Факты про UK проверяй, если не уверен,
  ищи на nhs.uk / gov.uk / qadamlondon.uk. Не уверен даже после поиска — не пиши;
- **героя**: Айгерим по умолчанию, Азиз — если тема мужская или нужен второй человек.

## Шаг 2. Тон (как на qadamlondon.uk)

- Говорим как друг, который сам через это прошёл. Спокойно, тепло, по делу.
- **Без нравоучений**: нет «вы должны», «обязательно», «не совершайте ошибку».
  Вместо этого: «можно», «попросите», «скажите вот так».
- Страх признаём, но не нагнетаем. Финал всегда даёт опору: следующий шаг.
- Готовые фразы по-английски с переводом — сильный приём, используй.
- **Границы проекта:** не даём индивидуальных иммиграционных консультаций и не оцениваем
  шансы. В роликах про убежище и статус финальная плашка: «Это объяснение, не консультация
  по вашему делу. По делу — к юристу IAA / SRA / BSB».
- Психологическая тема: без диагнозов и советов «просто держитесь». Признать, что тяжело,
  дать одно маленькое действие и контакт помощи (Samaritans 116 123, круглосуточно, бесплатно).
- Призыв в конце: бесплатный пошаговый план — ссылка в шапке профиля, или бот @QadamLondonBot.
  Не ставь e-mail в ролик.

## Шаг 3. Сценарий → `scenario.md`

Хронометраж 30–45 секунд, 4–6 сцен. Первые 2 секунды — крючок: вопрос или ситуация,
в которой зритель узнаёт себя. Закадровый голос на русском, коротко: 2–3 фразы на сцену.

Шаблон:

```markdown
# <Тема>

- **Главный вопрос:** …
- **Герой:** …
- **Хронометраж:** ~NN сек, N сцен
- **Факты проверены:** <дата> (источник: …)

## Сцена 1 · 0:00–0:05 · <название>
- **Кадр:** что видно (по-русски, 1–2 предложения)
- **Голос:** «…»
- **Текст на экране:** «…» (накладывается при монтаже)

… остальные сцены …

## Подпись к посту
<3–5 строк: суть, полезные номера при необходимости, призыв>

<5–8 хэштегов>
```

## Шаг 4. Промпт на каждую сцену → `prompts/scene-NN.md`

Промпт — **один абзац на английском, 90–200 слов**, в таком порядке:

1. Якорь STYLE из style-guide.md — дословно.
2. План и ракурс: `Medium shot, eye-level` / `Close-up` / `Wide establishing shot, low angle` и т.п.
   Чередуй планы между сценами.
3. Герой: полное описание из style-guide.md — дословно.
4. Действие и эмоция: что делает, что чувствует лицо и поза.
5. Место: детали британской среды, без читаемого текста.
6. Свет и настроение.

Запрещено в промпте: кириллица, читаемый текст и надписи, бренды, флаги, полиция,
плейсхолдеры вида `<...>` или `[...]`, обращения к человеку («insert», «your»).

Шаблон файла:

````markdown
# Сцена N · <название>

**Что в кадре:** <по-русски, 1 предложение>

## Prompt

```text
<промпт>
```

## Negative prompt

```text
<негативный промпт из style-guide.md, при необходимости дополненный>
```

## Параметры

- Формат: 9:16, 1080×1920
- Связь со сценарием: сцена N в scenario.md
````

## Шаг 5. Проверка

```bash
python3 "$CLAUDE_PROJECT_DIR/tools/check_prompts.py"
```

Скрипт проверяет файлы и собирает `prompts/prompts.json`. Если он нашёл ошибки —
исправь и запусти снова, пока не будет `OK`.

## Шаг 6. Ответ Тимуру

Простыми словами, без технических деталей: тема, сколько сцен и секунд, герой,
ссылки на `scenario.md` и папку `prompts/`. Отдельно скажи, какие факты стоит
перепроверить перед публикацией, если такие есть.
